## 解決済みの知見

| 日付 | 内容 | 対応 |
|---|---|---|
| Sep 25, 2026 | Isaac Sim 付属の HolonomicController は力のつり合いを解く方式で、O3dyn では速度が約 1/3、旋回が逆符号になる | メカナムの逆運動学を自前で計算（`sim/o3dyn_bringup.py`） |
| Sep 25, 2026 | SICK nanoScan3 の RTX LiDAR モデル（ソリッドステート型）は 1 スキャン（約 30 ms）が描画フレームに収まらず、LaserScan の約 3 割が欠ける。accumulateOutputs・tick rate の変更でも安定しない | 回転型 2D LiDAR（Example_Rotary_2D）を安全スキャナ相当の距離設定で代用 |
| Sep 25, 2026 | omap（占有格子地図の生成拡張）のバッファは x 方向が反転した並び。環境 USD を直接開くのと参照で読み込むのとで境界も変わる | 180° 回転して画像化し、シミュレーションと同じく参照で読み込んで生成（`sim/tools/generate_map.py`） |
| Sep 25, 2026 | O3dyn の USD は translate の xformOp を持っているため、XformCommonAPI で初期位置を設定しても効かない | 既存の op を直接書き換える |
| Sep 25, 2026 | Isaac Sim の真値オドメトリのままワープすると `/odom` も飛び、自己位置喪失が再現できない | ワープの前後で `/odom` が連続するよう補正し、真値は `/sim/ground_truth` に出す |
| Sep 25, 2026 | 回転型 LiDAR を角に置くと、視野の一部に車体が映る | scan_merger で車体外形 + 余裕の範囲の点を除く |
| Sep 25, 2026 | nav2_simple_commander の `waitUntilNav2Active()` は AMCL の初期位置を自分で設定しようとして待ち続ける | ノードの起動だけを待つ（`sim/tools/send_goal.py`） |
| Sep 25, 2026 | ROS 2 の source で入る pytest プラグイン（launch_testing, launch_ros）は pytest 9 と互換がない | `mission_server/pyproject.toml` で読み込まない設定 |
| Sep 25, 2026 | gRPC の Python サーバは既定で SO_REUSEPORT を使うため、同じポートで 2 つ目のサーバが起動でき、リクエストが新旧に振り分けられる | `grpc.so_reuseport=0` を指定し、2 つ目は起動に失敗させる |
| Sep 25, 2026 | 実行記録（TaskEvent）の robot_state に遷移前の状態が入っていた | 遷移後の状態を記録するよう修正 |
| Sep 25, 2026 | Isaac Sim の `python.sh` を kill しても、子プロセスの Isaac Sim 本体は止まらない | `start_sim.sh` はプロセスグループで起動・停止する |
