# 開発ロードマップ

Sep 25, 2026 作成

[locomotion_spec.md](locomotion_spec.md) の機能を、シミュレーション上で段階的に実装するための計画。
各ステップの最後に「シミュレーションで確認できること」を置き、仕様とコードを並行して直しながら進める（仕様書 9 章）。
実装・試験で見つけた課題は [notes.md](notes.md) に記録する。

## 方針

- ミッションサーバは **Python**（rclpy + grpcio）で実装する
- UI はまず **PySide6 のローカルアプリ**として作り、最終的にブラウザへ移す。UI は gRPC API のクライアントに徹し、ROS 2 には直接触れない（ブラウザ版に移すとき、差し替えるのは画面だけにする）
- 異常の再現（安全停止・機器異常・ワープ）は、製品の UI とは別の**テストパネル**で行う
- ミッションサーバから見た ROS 2 の接点は、シミュレーションと実機で同じにする（仕様書 9 章）

## ステップ 1: ミッションサーバの骨格（移動と状態管理）

サーバを「状態管理の中核」「ROS 2 アダプタ」「gRPC サービス」の 3 層に分ける。中核は ROS 2 にも gRPC にも依存させない。

- [x] **1-1 proto の配置とコード生成**: `doc/locomotion.proto` を `proto/locomotion/v1/` へ移し、Python コードを生成する仕組みを作る（`grpcio-tools` を `.venv` に追加）
- [x] **1-2 状態遷移の中核**: 仕様書 4 章の遷移表をデータとして持ち、受理・拒否（FAILED_PRECONDITION）の判定とタスクの結果（成功・中断・失敗）を決める。**遷移表の各行を単体テストにする**
- [x] **1-3 ROS 2 アダプタ**:
  - Nav2: `NavigateToPose` / `NavigateThroughPoses` の送信・キャンセル、フィードバック（リカバリ回数 → 回避動作中）
  - AMCL: 推定位置と共分散（自己位置の良否判定）、初期位置の設定
  - 安全系: `/safety/state` の購読、`/safety/reset` の送信
  - 指令切替ノード: モードの切り替え
- [x] **1-4 地点の保存（最小）**: 1 枚の地図の中の地点 ID と姿勢を保存する
- [x] **1-5 gRPC サービス**: `RobotService`（GetStatus / WatchStatus / WatchPose / SetMode / SetInitialPose / ResetSafetyStop）と `TaskService`（StartTask / PauseTask / ResumeTask / StopTask / RetryTask / GetTask / ListTasks）。地点の登録は `PointService` の最小限（CreatePoint / ListPoints）
- [x] **1-6 確認用のコマンドラインクライアント**

**確認できること**
- コマンドラインから地点 ID を指定して移動し、一時停止・再開・停止ができる
- テストパネルで保護停止をかけると「移動中 → 安全停止」、解除すると「一時停止」へ遷移し、再開で移動が続く
- 状態が許さない操作は FAILED_PRECONDITION で拒否される

## ステップ 3: 地図作成（前倒し）

現場への導入で最初に行う作業のため、セットアップ機能から前倒しする（Sep 25 決定）。ジョイスティックモードでロボットを動かしながら地図を作る（仕様書 4 章）。

- [ ] **3-1 SLAM の組み込み**: slam_toolbox の起動・停止と、AMCL・ナビゲーションとの切り替え（地図作成中は AMCL とナビゲーションを止める）
- [ ] **3-2 地図作成の API**: StartMapping / WatchMappingPreview（1 Hz の縮小画像）/ SaveMapping / DiscardMapping。保存時は占有格子と追加スキャン用の SLAM データを残し、最終推定位置を初期位置として引き継ぐ
- [ ] **3-3 地図の読み込みの一本化**: Nav2 の起動時の地図も `data/` の使用中の地図から読む（notes.md の課題 5）
- [ ] **3-4 地図作成画面（S4）**: 生成中の地図、ロボットの位置、操作パッド、保存・破棄

**確認できること**
- シミュレーションの倉庫で、ゲームパッドまたは操作パッドで走行しながら新しい地図を作り、保存した地図で Nav2 の移動ができる
